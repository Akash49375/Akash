✨ Features

🎯 Cursor Control: Move your mouse cursor by moving your index finger
👆 Click Gesture: Perform clicks by touching your thumb and index finger together
🎥 Real-time Tracking: Smooth hand landmark detection at 20-30 FPS
🪶 Lightweight: Uses minimal system resources
🔧 Customizable: Adjustable sensitivity and smoothing parameters
🖥️ Cross-Platform: Works on Windows, macOS, and Linux

🛠️ Technologies Used

OpenCV: Real-time video capture and image processing
MediaPipe: Google's ML solution for hand landmark detection
PyAutoGUI: Cross-platform GUI automation for cursor control
Python: Core programming language

📋 Prerequisites

Python 3.7 or higher
Webcam (built-in or external)
Windows/macOS/Linux operating system

🚀 Installation
1. Clone the Repository
bashgit clone https://github.com/yourusername/hand-gesture-mouse-control.git
cd hand-gesture-mouse-control
2. Create Virtual Environment (Optional but Recommended)
bash# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
3. Install Dependencies
bashpip install -r requirements.txt
Or install manually:
bashpip install opencv-python mediapipe pyautogui
💻 Usage
Basic Usage
bashpython app.py
